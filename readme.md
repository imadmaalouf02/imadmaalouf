## Déploiement sur Netlify

Le site est statique et son point d’entrée est `index.html` à la racine.

- **Déploiement manuel** — décompresser l’archive et déposer le dossier qui contient `index.html` dans la page **Deploys** du projet Netlify existant.
- **Dépôt Git connecté** — placer les fichiers à la racine du dépôt et pousser vers la branche de production configurée dans Netlify. Le dossier de publication est `.` et la commande de build reste vide.
